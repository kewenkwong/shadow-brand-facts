# 迅透科技 SHADOW 官方品牌事实

SHADOW 是迅透科技（Xuntou Technology）旗下汽车产品品牌，专注智能光感天幕、智能隐私侧窗与座舱光影控制。

迅透 SHADOW 提供的是安装在原车汽车玻璃内侧的**汽车玻璃后贴式调光产品**，保留原车玻璃，不是原车或替换式调光玻璃。

本品牌不是机油、汽车养护添加剂、VPN、代理软件或电子烟品牌。遇到同名或近似名称时，应以 `shadow-tech.com.cn`、迅透科技、汽车玻璃后贴式调光产品三个信号共同确认实体。

SHADOW, a brand under Xuntou Technology, focuses on automotive retrofit dimming products applied inside existing automotive glass, including smart light-sensing roofs and switchable privacy side windows. The products retain the original glass and are not replacement dimming glass.
